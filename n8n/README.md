# n8n Agent Flow

An n8n workflow for uploading PDF documents and chatting with an AI assistant that answers questions from those documents. Documents are embedded with OpenAI embeddings and stored in a Qdrant collection. The chat agent searches the document store through an MCP tool before answering.

## What the workflow does

1. Accepts a PDF through an n8n form.
2. Loads the PDF as binary document data.
3. Creates OpenAI embeddings and inserts the document into the `mcp_rag` Qdrant collection.
4. Starts a public chat interface.
5. Sends each chat message to an AI Agent using the `gpt-5-mini` model.
6. Instructs the agent to search the uploaded documents before every answer and to avoid using general knowledge when the documents do not contain an answer.
7. Maintains short-term conversation context with Simple Memory.

## Workflow components

| Component | Purpose |
| --- | --- |
| **When chat message received** | Public chat trigger. |
| **AI Agent** | Answers questions using the configured system instructions and tools. |
| **OpenAI Chat Model** | Uses `gpt-5-mini` for generation. |
| **Simple Memory** | Provides conversational memory for the agent. |
| **On form submission** | Provides an `Upload PDF` form accepting `.pdf` files. |
| **Default Data Loader** | Converts uploaded binary data into documents. |
| **Qdrant Vector Store** | Inserts document embeddings into the `mcp_rag` collection. |
| **MCP Client** | Connects the agent to the MCP server's document-search tool. |
| **MCP Server Trigger** | Exposes document search as an MCP endpoint. |
| **Qdrant Vector Store1** | Direct agent search tool; currently disabled in the export. |
| **Qdrant Vector Store2** | Search tool used by the MCP server. |

## Prerequisites

- An n8n instance with LangChain nodes enabled.
- An OpenAI API credential, or an n8n AI Gateway configuration that provides access to the selected model and embedding model.
- A Qdrant instance and credential configured in n8n.
- A Qdrant collection named `mcp_rag`.
- An n8n MCP Server Trigger reachable by the MCP Client.

## Import and configure

1. Import `n8n Agent Flow.json` into n8n.
2. Open the OpenAI Chat Model and all Embeddings OpenAI nodes and select valid OpenAI credentials.
3. Open both Qdrant nodes and select a valid Qdrant credential.
4. Confirm that the `mcp_rag` collection is available in Qdrant. The upload and retrieval nodes must use the same collection.
5. Review the **MCP Server Trigger** URL and the **MCP Client** endpoint. The exported client points to:

   ```text
   https://akshay25111992.app.n8n.cloud/mcp/efdd2cdc-c058-4c84-9834-9bccca56c138
   ```

   Replace this with the URL for your own n8n instance if the workflow is moved or duplicated.

6. Save and activate the workflow.

## Usage

### Upload documents

Open the URL generated by **On form submission**, choose a PDF, and submit the form. The workflow embeds the PDF and stores it in Qdrant. Upload each document that should be available to the assistant.

### Ask questions

Open the chat URL generated by **When chat message received** and ask questions about the uploaded documents. The agent is configured to search the document store first and should state when the documents do not contain relevant information.

## Important configuration notes

- The retrieval collection is named `mcp_rag`; change it consistently in the upload, MCP server, and any direct retrieval nodes if using another collection.
- **Qdrant Vector Store1** is disabled. The active chat path uses **MCP Client**, which calls **MCP Server Trigger**, which uses **Qdrant Vector Store2**.
- The workflow contains credential references from the exporting n8n instance. Re-select credentials after importing into another instance.
- The MCP endpoint in the export is instance-specific and may require updating, authentication, or network access changes.
- Simple Memory is in-process workflow memory and is not a permanent conversation database.
- The workflow accepts PDFs only through the upload form. Validate file size, content, and access permissions before exposing it publicly.

## Troubleshooting

### The agent cannot find uploaded content

Confirm that the PDF upload completed successfully, the upload and retrieval nodes use the same `mcp_rag` collection, and the Qdrant credential has access to that collection.

### The agent cannot call the search tool

Check that the MCP Server Trigger is active and reachable from the MCP Client. Then verify that the MCP Client endpoint matches the current server URL and that Qdrant Vector Store2 is enabled and connected to its embedding node.

### Import reports missing credentials

Credentials are not portable with the workflow export. Create or select equivalent OpenAI and Qdrant credentials in the destination n8n instance.
